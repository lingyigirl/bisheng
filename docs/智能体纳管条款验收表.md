# 公告（五）3「智能体纳管」验收表

> 条款原文：「智能体纳管：统一纳管本平台、其他低代码平台或高码开发的第三方智能体，实现统一接入、调度与运营；支持按场景/行业/标签分类展示。」
> 本表用于现场验收；前置条件未满足时，相关行无法通过。

## 1. 前置条件

| 条件 | 操作 | 判定 |
|---|---|---|
| 功能开关 | `managed_agent.enabled: true`，重启 API/worker | 平台「构建 → 智能体纳管」可见；关闭时路由 404、菜单隐藏 |
| FGA 模型 | 执行 `scripts/migrate_fga_add_managed_agent_type.sh --apply`，按输出 pin/重启 | 创建纳管智能体不报 FGA/无权限错误 |
| 外部调用 | F076 总闸 `open_api.enforce_keys: true`；密钥带 `managed_agent:invoke`；服务账号被授予目标智能体 editor | `POST /api/v2/managed-agent/invoke` 返回 200 |
| Celery beat | `backend_beat` 或等价 beat 常驻 | 定时任务计划轮次按时触发 |
| 出站 allowlist | 配置目标智能体域名/端口（空 = 全部拒绝） | 健康检查/调用不被 12111 拒绝 |

## 3. 明确不做

- A2A Agent Card 自动发现/任务生命周期、流式/SSE（Phase 2）。
- 具名低代码连接器（Coze/豆包/钉钉等）；本期只做通用 OpenAI-compatible / 自定义 HTTP。
- 应用市场/交易/计费、评测集成、故障转移、自动扩缩容。
- 把第三方智能体写入 `flow`/`assistant` 表或扩展 `FlowType`。
- 代表用户调用/OAuth2 授权服务器。
