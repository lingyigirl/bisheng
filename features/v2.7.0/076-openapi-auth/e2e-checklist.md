## 1. 自动化

**文件**：`src/backend/test/e2e/test_e2e_openapi_auth.py`
**环境**：真后端 + 真中间件（MySQL / Redis 必须在线）。测试自建服务账号与密钥，数据前缀 `e2e-openapi-`，双 cleanup（setup 清上次残留 + finally 清本次，失败带证据）；每个 allow 配一个 deny；118xx 断言**真 HTTP 状态 + 信封业务码**两个都对。

**前置（缺一则整模块 skip，原因写在 skip 信息里）**：
1. 后端在 `E2E_API_BASE`（默认 `http://localhost:7860/api/v1`）可达；
2. **部署总闸 `open_api.enforce_keys: true`**（配置文件 + 重启）——总闸关时 `/api/v2` 是逐字旧行为，本套用例无从验证；
3. 管理员口令经 `E2E_ADMIN_PASSWORD` 传入（多租户/非默认口令环境必须设）。

**运行命令**：

```bash
cd src/backend
E2E_ADMIN_PASSWORD='<管理员口令>' uv run python -m pytest test/e2e/test_e2e_openapi_auth.py -v
# 或：.venv/bin/python -m pytest test/e2e/test_e2e_openapi_auth.py -v
```

**最近一次运行（2026-10-16，本机 dev，总闸临时打开、跑完已还原）**：`10 passed`。
