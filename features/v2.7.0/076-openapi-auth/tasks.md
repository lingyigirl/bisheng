## 开发模式

- **Wave 组织**：W1 鉴权内核（基础设施优先：契约→骨架→模型→错误码→服务→门禁）→ W2 工具参数 / W3 管理面（并行，均依赖 W1）→ W4 审计与文档（依赖 W1–W3）→ W5 联调切换（依赖全部）。Wave 内除标注依赖外可并行。
- **Test-First 配对**：后端任务把单测/契约测试写在同一行的「验证标准」里（与 F065 先例一致）；守卫测试（T-10）属 W1 交付物，不后补。
- **命名约定**：新文件路径为**拟定路径**，与既有目录约定冲突时可调整，但必须保持 design §4.3 的职责边界。
- **自包含**：每任务内联文件与逻辑；设计论证指向 design §X，不复制；前驱产出形状以 design §4.2 为准（如 `OpenApiPrincipal`、scope 注册表条目、信封字段）。
- **AC 追溯**：spec 全部 43 条 AC（AC-01~AC-41 + AC-06a + AC-35a）均有任务覆盖；测试任务逐条列举 AC，不用范围写法。
