# 实施差异自审

范围为本次 Skill 对象存储变更，按仓库 code-review 规则检查租户/权限、发布一致性、资源限制、异常、日志与文档；未调用独立审查 Agent。

已修复的发现：

- 并发创建缓存目录时 Windows resolve 的中间状态误判：改用规范根内路径与逐级 reparse/symlink 检查，冷读并发测试证明同进程单次下载。
- 缺失文件被旧 provisioning 跳过：改为所选包明确拒绝，阻止未装载 Skill 却宣称执行成功。
- ZIP 解压在总量检查前发生：改为先核对归档声明、数量和路径，再解压，实际读取仍有总量校验。
- 缓存同版本重发不必要删除：有效目录保留，避免其他进程读到被删除的完整缓存。
- 同步压缩/IO 阻塞异步请求：移入线程；主/成员装载一次读取完整映射，避免每文件重复校验和多包累计占用。
- CLI 懒注册资源未跟随应用关闭顺序：显式在事件循环关闭前 dispose 数据库，第三次只读预览复核无回收异常。

未发现剩余阻塞源码问题。环境限制保留：OpenFGA 类型/owner 补偿未完成、原五个包源文件缺失、其他远端节点尚未部署同版、DM8 实机待中央验证；本机 API 曾退出并已恢复，原因未确认。详见 e2e-report.md，不以本次自审代表以上环境均已验收。
