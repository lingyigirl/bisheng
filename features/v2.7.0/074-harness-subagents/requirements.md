# F074 需求来源与范围记录

日期：2026-10-13。来源：本次用户会话中的 WBS 1.3、方案讨论及“你直接开始吧，新开一个分支”。

## 原始需求

支持基于 Harness 自主规划模式构建：云端沙箱、Agentic Loop（推理—工具调用—结果回传—计划调整）、会话/长期记忆、隔离执行环境、工具注册调用；按任务目标自主规划、调用工具并迭代执行；长时任务流式反馈、断线重连、断点续跑；子 Agent 独立配置名称、提示词、模型、Skills、工具与连接器，主 Agent 路由调度、整合结果。

## 会话中已明确的约束

- 用户只负责 WBS 1.3；8.2 长期记忆和 8.3 记忆治理由其他负责人负责。
- 优先快速交付、控制改动范围，使用 Codex 开发。
- 在现有灵思上扩展 deepagents，复用 Worker、E2B、工具和工作空间。
- 工作空间增加协作成员选择、编辑和执行展示。
- 新建独立分支，开始工作。
- 目标第一天下午形成核心闭环，三天完成联调与验收；不是对实际测试结果的预先承诺。

## 交付边界

1. 核心交付为可配置子 Agent、准确执行展示、流式补播、现有人工中断恢复回归。
2. 云端沙箱按任务级代码执行隔离验证，不宣称每个子 Agent 有独立容器。
3. 长期记忆只定义、适配读取和候选经验提交契约；服务实现、画像与治理不属于 F074。
4. 进程崩溃恢复列为验证工作：只有经故障注入证明可安全重放的路径才可开放受控恢复；未知副作用工具禁止自动重试。不能将消息重连或人工输入恢复标为任意崩溃恢复。
5. 原始需求中的全场景崩溃续跑、长期记忆和独立子 Agent 容器仍须分别标记依赖/缺口，不把本期交付计为原始 WBS 全量满足。
