## 问题清单

### 1. P1：API 恢复后，全屏错误遮罩不自动消失

复现：任务运行中停止 API，Vite 代理返回 500，网页出现“系统出了点小状况 / 刷新重试”。API 恢复健康 200，底层任务事件继续、计划推进到 3/6，但两个页面仍被全屏遮罩覆盖，必须点击“刷新重试”才能操作。

根因：`src/frontend/client/src/api/request.ts:168,216` 在 500 时发送 `bs:service-maintenance`；`src/frontend/client/src/components/SystemMaintenanceOverlay.tsx:23` 只执行 `setVisible(true)`，没有恢复路径。该遮罩会覆盖整个工作区，阻断长任务断线后的自动恢复体验。

建议：区分任务连接中断与全局不可用；恢复成功后解除遮罩，并保留任务游标重连能力。回归应覆盖服务恢复时无需刷新即可继续查看/操作。

截图：`src/backend/.venv/f074-evidence/web-1018-reconnected-error-overlay.jpg`。

### 2. P1：后台子 Agent 卡片将启动回执误当成最终结果

计算员真实执行约 95 秒（02:07:23.157—02:08:58.151），网页卡片却显示“已完成 · 5s”。展开“结果”得到的是“已放入后台：job_1……完成前用 job_output”，而不是计算员最终报告。最终结果能被主 Agent 收集，但原卡片的完成状态、耗时、结果不代表子任务实际生命周期。

根因：`background_subagents.py` 返回启动成功 ToolMessage，后台结算只更新 job registry；`SubagentRunCard.tsx:18,31,40` 直接根据原调用 step 的 running/output 显示完成和结果，没有关联后续 job 的结算状态。

建议：以稳定 job_id/run_id 关联后台启动、运行、完成/失败、耗时及最终结果，并在回放中恢复同一卡片。

截图：`src/backend/.venv/f074-evidence/web-1018-background-result-card.jpg`。

### 3. P2：网页无法选择已有授权连接器，历史配置也隐藏该字段

同一登录账号的 `/api/v1/tool` 返回有使用权限的自定义组 17 / 工具 39（`f074_multiply`），但工作区配置仅提供联网搜索、代码执行器两组预置工具。成员编辑器使用这份 `options.tools`，因此没有自定义连接器选项。

另外打开已有连接器验收任务：后端快照明确保存 `connector_refs=[39]`，只读编辑器却只显示两个未勾选的预置工具，实际配置不可见。该历史任务的连接器执行来自之前验收，本轮没有通过网页新配置并再次执行连接器。

定位：`SubagentEditor.tsx:61` 依赖传入工具目录；`ChatView`/`AiChatInput` 传入工作区配置。建议使用经过权限过滤的完整可选能力目录，并确保历史快照中已选但当前目录缺失的能力能展示其状态。

证据：`review-1018-web-connector-catalog.json`、`web-1018-hidden-connector.jpg`。

### 4. P2：等待后台子任务的轮询开销过高

上述 4 行表格任务中，主 Agent 调用模型 32 次，累计输入 647145 tokens；子 Agent 9 次，输入 61524 tokens，合计 708669 tokens。主 Agent 调用 `job_output` 18 次、`job_list` 2 次，并出现借代码执行器 sleep 后再查询的等待方式。这是实际计数，并非费用估算；API 中断及模型策略可能影响该次样本，不能直接推广到所有任务。

定位：`background_subagents.py:368` 的 job_output 在未完成时立即返回运行中状态，没有有界等待/挂起能力。建议提供受控等待与完成唤醒，减少由模型反复决定轮询和调用沙箱等待的成本。

证据：`review-1018-web-full-usage.json`、`review-1018-web-full-completed.json`。

### 5. P2：CSV 不能作为任务输入上传

网页上传测试 CSV 被提示“该应用不支持上传此类型文件”；改成同内容 XLSX 后成功。`src/frontend/client/src/common/index.ts:10` 的任务文件白名单包含 xls/xlsx，但没有 csv。输出支持 CSV 下载，输入却不能接回同类文件，限制数据处理任务的闭环。

建议：核对后端文件处理能力与大小/内容校验后，统一任务输入格式支持；不能只修改文件选择器后缀。
