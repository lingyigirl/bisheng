- API 恢复慢于 3 秒时页面放弃重连：改为运行期间持续指数退避，成功重置、结束/卸载取消。

- 默认子 Agent 自动注入：用受控 general-purpose 覆盖，并保留稳定 UI ID。
- 成员资源撤权后仍可调用：增加每次模型/工具调用的资源检查。
