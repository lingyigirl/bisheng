## 1. 用户故事

作为 **终端用户（企业员工）**，
我希望 **在智能体广场按类型、标签、关键词快速找到已发布的应用，并在进入前预览其介绍与活跃度**，
以便 **准确找到需要的应用，避免逐个打开试错**。

作为 **终端用户**，
我希望 **收藏常用应用、并能在广场看到自己的最近使用记录**，
以便 **下次快速进入，不用重复搜索**。

作为 **终端用户（浏览者）**，
我希望 **在卡片与预览中看到应用的访问量、成功率等统计**，
以便 **判断应用的活跃度与可靠性，决定是否使用**。

## 2. 验收标准

### 2.1 展示与搜索

- **AC-01** — THE SYSTEM SHALL 在「智能体广场」以卡片网格分页展示当前用户可见（`view_app` 权限）的全部已上线（status=ONLINE）工作流与助手应用。
- **AC-02** — THE SYSTEM SHALL 每张应用卡片展示：应用名称、图标、描述、标签、近 7 天访问量。
- **AC-03** — WHEN 用户输入关键词, THE SYSTEM SHALL 按应用名称与描述模糊匹配过滤列表并刷新分页。
- **AC-04** — IF 列表无匹配应用或用户无可见应用, THEN THE SYSTEM SHALL 展示空态（含跳转引导）。

### 2.2 多维度分类筛选

- **AC-05** — THE SYSTEM SHALL 支持按应用类型筛选（助手 / 工作流）。
- **AC-06** — THE SYSTEM SHALL 支持标签多选筛选；WHEN 用户选中多个标签, THE SYSTEM SHALL 返回包含**任一**选中标签的应用（OR 语义）。
- **AC-07** — THE SYSTEM SHALL 支持排序切换：最近使用（默认：用户使用过的应用优先）、最新上线（按更新时间倒序）、最多访问（按近 7 天访问量倒序）。
- **AC-08** — WHEN 类型、标签、关键词、排序组合使用, THE SYSTEM SHALL 各条件同时生效且分页正确。

### 2.3 详情预览

- **AC-09** — WHEN 用户点击应用卡片, THE SYSTEM SHALL 打开详情预览抽屉，展示名称、图标、描述、标签、访问统计（近 7 天访问量、累计访问量、成功率、平均响应时间）。
- **AC-10** — WHEN 用户在预览抽屉点击「开始对话」, THE SYSTEM SHALL 进入该应用的会话页（沿用既有 `use_app` 预检流程；无权限时给出既有提示，不新增分支）。
- **AC-11** — IF 预览数据加载失败, THEN THE SYSTEM SHALL 在抽屉内展示错误态并支持重试。

### 2.4 应用收藏

- **AC-12** — WHEN 用户在卡片或预览抽屉点击收藏, THE SYSTEM SHALL 将该应用加入该用户的「我的收藏」并持久化（同一用户对同一应用仅一条记录）。
- **AC-13** — WHEN 用户对已收藏应用再次点击收藏按钮, THE SYSTEM SHALL 取消收藏并从「我的收藏」移除。
- **AC-14** — THE SYSTEM SHALL 在广场展示「我的收藏」区块（含收藏应用卡片，点击进入预览抽屉）；IF 用户无收藏, THEN THE SYSTEM SHALL 展示空态引导。
- **AC-15** — THE SYSTEM SHALL 收藏仅对收藏者本人可见（用户级隔离，不跨用户、不跨租户）。
- **AC-16** — IF 已收藏应用被下架（OFFLINE）或对用户不可见, THEN THE SYSTEM SHALL 不再在广场列表与「我的收藏」中展示该应用（收藏记录保留，重新可见后恢复展示）。

### 2.5 历史记录

- **AC-17** — THE SYSTEM SHALL 在广场展示「最近使用」区块（按该用户最近使用时间倒序，最多 10 个应用），点击进入预览抽屉。
- **AC-18** — IF 用户无任何使用记录, THEN THE SYSTEM SHALL 展示空态。

### 2.6 应用访问统计

- **AC-19** — THE SYSTEM SHALL 提供广场统计只读接口，对给定应用集合返回每个应用的：近 7 天访问量、累计访问量、成功率、平均响应时间（口径与 F046 一致：一次应用运行 = 一次访问，成功率 = 成功运行数 / 总运行数）。
- **AC-20** — WHEN 用户选择「最多访问」排序, THE SYSTEM SHALL 按近 7 天访问量倒序返回应用列表。
- **AC-21** — THE SYSTEM SHALL 统计随 `application_process` 遥测事件同步更新，可见延迟不超过 5 分钟（与 F046 中间表同步周期一致）。
- **AC-22** — IF 应用暂无访问数据, THEN THE SYSTEM SHALL 展示为 0 / 空值占位，不报错。

### 2.7 权限与隔离

- **AC-23** — WHERE 多租户开启, THE SYSTEM SHALL 广场列表、收藏、最近使用仅包含当前租户可见应用与当前用户数据。
- **AC-24** — THE SYSTEM SHALL 不改变既有权限模型（列表可见性 `view_app`、进入会话 `use_app`），不新增权限位。

## 3. 边界情况

- 应用被删除：广场 / 最近使用 / 收藏中不再展示该应用（后端过滤不存在的应用 id，不报错）
- 标签被删除：对应筛选入口消失；已打该标签的应用不受影响
- 收藏按钮连点：收藏 / 取消收藏幂等（按用户+应用去重）
- 应用改名 / 换图标：广场、收藏、最近使用实时反映最新信息（不缓存旧快照）
- 统计中间表同步中断：访问量保持上次同步值，不报错（恢复后自动追上，见 AC-21）
- 访客 / 无登录态：广场不可访问（客户端入口受既有登录流程约束，行为不变）
