# E2E 验证清单: 机构/部门标记与树形知识库可见范围（062）

**测试环境**: Platform `http://localhost:3001` · Client `http://localhost:4001/workspace` · Backend `:7860`
**前置条件**:
- 以**系统管理员**登录（改标记需要该权限；部门管理员会被拒——这本身是 AC-04 的验证点）
- 准备三个账号：**超管**（改标记）、**U1**（挂在「信贷审批部2」）、**U2**（挂在「信贷研发」）
- 在平台组织管理页建出下面这棵树：

```
总行/省联社            (0-机构, 默认)
├── 信贷研发           (标为 1-部门)
├── 信贷审批部         (标为 1-部门)
└── 一级分行           (0-机构, 默认)
    ├── 信贷审批部1    (标为 1-部门)
    └── 信贷审批部2    (标为 1-部门)
```

给上述 6 个节点**各挂一个组织知识库**（文档库），并建一个**二级支行**（保持 `0-机构`）挂在 `一级分行` 下、也挂一个库——它用于验证嵌套机构屏障。

> 依赖：组织树标注是**交付实施动作**，本特性上线后不会自动生效。

## Platform 前端

### AC-08a: 树节点呈现机构/部门标记
- [ ] 打开组织管理页，左树每个**部门**节点带「部门」徽标
- [ ] **机构**节点**不带**徽标（其缺席本身表示「机构」——机构是默认态，标它等于加噪音）
- [ ] 部门**选择器**（如权限授权弹窗里的部门选择）**不显示**该徽标

### AC-03 / AC-20: 标记编辑入口
- [ ] 选中一个节点 → 「设置」页 → 基本信息区能看到「节点类型」单选（机构 / 部门）
- [ ] 以**超管**身份可切换；以**部门管理员**身份该控件为**禁用**（AC-04）
- [ ] 保存后刷新，选择保持不变

### AC-03: 创建入口也能选节点类型
- [ ] 左树任一节点点「+」（或底部「+ 创建」）→ 创建弹窗里出现「节点类型」单选，**默认机构**
- [ ] 以**部门管理员**身份：该控件**可用**（与设置页相反，这是有意的——见下方「已知未实现」）
- [ ] 选「部门」→ 提交 → 新节点在树上带「部门」徽标，刷新后仍在
- [ ] **父节点是「部门」时，弹窗默认仍为机构**（AC-03：标记不继承）
- [ ] **停在「设置」Tab 时**点树的「+」打开弹窗 → 两个单选的 label 点击仍能正确切换（`f062-node-type-*` 与创建弹窗的 id 必须不同：共 id 时 label 会绑到设置页那组，因为弹窗经 Portal 挂在 body 末尾）
- [ ] 创建**不弹**影响面确认框（AC-05 只覆盖翻转 / 移动 / 批量；新节点名下必为 0）

### AC-05: 翻转前的确认弹窗
- [ ] 把 `一级分行` 从「机构」改成「部门」→ 提交时**弹出确认框**
- [ ] 弹窗显示**具体数字**（N 个部门 / M 个知识库），不是笼统提示
- [ ] 点**取消** → 不生效，树上的徽标不变
- [ ] 点**确认** → 生效
- [ ] 用**关闭按钮（X）**关闭弹窗 → 保存**不得卡死**（这是 `bsConfirm` 三出口的已知陷阱）

### AC-08: 空状态引导条
- [ ] 在**全新租户**（全部默认机构）打开组织管理页 → 顶部出现引导条
- [ ] 点「不再提示」后消失，刷新后不再出现
- [ ] 标记任一节点为「部门」后，引导条自动消失

## Client 前端

### AC-09 / AC-10 / AC-11: 核心可见范围（本特性的存在意义）
- [ ] U1（信贷审批部2）登录客户端 → 打开知识库选择器 → 组织知识库分组
- [ ] 应看到**恰好 6 个**节点下的库（含**兄弟部门** `信贷审批部1` 的库——这条最容易漏）
- [ ] U2（信贷研发）看到的结果与 U1 **完全相同**（同处一级分行机构域）
- [ ] ⚠️ **回归重点**：升级前这里的数量会少——候选集若仍是祖先链，兄弟部门的库不会出现

### AC-12 / AC-12a: 嵌套机构屏障
- [ ] U1 **看不到** `二级支行` 本身的库
- [ ] U1 **看不到** `二级支行` 下任何部门的库

### AC-17: 横流来的库只有查看/使用权限
- [ ] U1 对 `信贷研发` 的库**可选中并用于问答**
- [ ] 但列表/详情里**没有**编辑、删除、成员管理入口

### AC-06: 翻转后立即生效
- [ ] 超管把 `一级分行` 改成「部门」→ U1 应**立即**能看到 `二级支行` 的库
- [ ] 改回「机构」→ 立即恢复不可见
- [ ] **10 秒内**用另一个账号核对：已收回的库**不应**再出现（验证判定缓存失效）
