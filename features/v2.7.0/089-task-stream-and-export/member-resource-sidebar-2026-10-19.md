# 成员资源侧栏优化

## 范围与验收标准

单模块前端交互优化，采用小功能轻量流程；不更改成员保存接口、资源授权或运行时配置结构。

- 基本信息和资源配置分为两个页签，避免基本字段和完整资源目录叠成长页面。
- 技能、工具、连接器分类切换，显示各类已选数及合计数量。
- 支持按名称、技能说明、工具所属服务搜索，以及只看已选。
- 列表固定高度、独立滚动；每页最多渲染 40 个资源，切换分类、关键词或筛选时重置页码。
- 搜索、翻页、切换分类和基本信息页签不能丢失已选资源及表单内容。
- 历史失效引用继续可见且可移除；只读模式允许浏览、搜索和翻页，但禁止编辑配置。
- 不增加 UI 库、全局状态或 HTTP 请求；沿用授权目录查询，缓存 60 秒，搜索和分页在本地完成。

## 实现

- `SubagentEditor.tsx`：基本信息 / 资源配置页签，显式禁用编辑控件，保证只读浏览控件仍可用。
- `SubagentResources.tsx`：三个分类、搜索、筛选、计数、受限列表和分页。
- 中英日三套翻译同步增加资源配置文案。
