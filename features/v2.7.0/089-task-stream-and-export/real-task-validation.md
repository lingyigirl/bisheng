## 测量口径

通过浏览器 CDP 观察正常 UI 提交、网络和 WebSocket，未修改浏览器网络或渲染行为。以提交操作时刻为起点，通过 request 的 wallTime/timestamp 对齐 WS 单调时钟；“思考”是首次非空 thinking，“正文”分别统计主/成员首次非空 assistant，结束是 final_result。首字不是 spinner，不将 thinking 冒充用户正文；这些是浏览器收到事件的时间，不是 GPU paint 的精确计时。原始证据保存在忽略目录 `src/backend/.venv/f089-evidence/real-runs/`，不提交工具正文和签名 URL。

## 发现与本轮处理

| 编号 | 实际问题 | 处理与边界 |
|---|---|---|
| P1 | 默认代码工具在模型开始前同步预热远端沙箱；纯问答也付出初始化成本，阻塞 worker 事件循环 | 任务绑定禁用预热，首个真实代码调用才初始化，后续继续复用；其它调用者默认行为兼容 |
| P2 | 等待期间固定显示“正在规划任务”，没有等待计时 | 准备/等待模型状态加独立计时，出现真实事件即由原时间线接管，不伪造模型正文 |
| P3 | 旧技能元数据存在、文件包缺失，仍在选择器展示，执行才失败 | 选择器过滤不可读取的无版本旧包；版本化技能不为下拉列表整包下载，运行时完整校验继续保留。旧业务包仍需从原部署恢复/迁移 |
| P4 | PDF共享资源导致无图页也出现在 image_pages，模型误以为图跨页 | 按页面实际绘制内容判断含图页，保留最多3页预算；图片资源数仍非视觉结论 |
| P5 | Excel公式无缓存，仅读缓存的网页预览为空；模型已明确承认 | 提示优先使用已有xlsxwriter保存公式及实算缓存值，并检查data_only读取；不为可选预览安装整套Office |
| P6 | 主智能体近3分钟没有普通正文，仅工具/思考；最终说明冗长 | 复杂任务首轮行动用一句正文；按字数/页数交付，避免反复复述计划 |
| P7 | 待办0/N持续到接近结束，无法反映实际进展 | 提示按阶段更新状态，避免每工具调用都重写，复测观察实际遵循 |
| P8 | 已选成员旧提示要求无关CSV、时间、版本、年龄连接器；主又添加第三次重复计算 | 保留用户成员配置；提示只派发本次验收，不因有某工具就附加连通性检查。配置残留单列，不冒充已修复 |
| P9 | 未要求的P90扩展出现错误：将PERCENTILE.EXC在8个样本p=.9时外推成249 | 限制无关指标扩展，要求函数边界与真实验证；不声称提示能保证所有模型数学结论正确 |
| P10 | 缺PDF库后额外探测/安装调用；绘图标签首版重叠触发重画，Word沙箱无LO | 实际核验先有界探测；只为必需步骤安装最小依赖。单次重画是有效质量修正；Word只做结构核对时明确说明，不能冒充已视觉验证 |
| P11 | 成员编辑器的模型选项透出技能文字与复选框 | 浏览器实测 Select 背景为 rgba(0,0,0,0)，--popover 未定义，并非层级不足；共享 Select 改用已定义的 bg-background/text-text-1。复测背景纯白、不透明度1、选项命中菜单且不越界，切换模型未改变任何技能/工具勾选；未保存用户成员配置 |
| P12 | 首轮复测仍安装Office：代码工具自身说明强制“缺依赖先安装”，还点名LO/Poppler，与系统性能规则冲突 | 同步修正工具说明，优先已有库、先探测、最小必需依赖，可选预览不安装LO/Poppler/Pandoc；追加R8同题验证，不再安装大型转换器。如确需严格页面验收，需已配置渲染能力，不能把结构检查当视觉检查 |
| P13 | 公式缓存修好后，网页仍将45%显示为0.45，丢失数字格式 | SheetJS读取改为格式化单元格值，保留百分比、日期、千分位；提取数据辅助函数使原文件降至591行，并保留0/false值。真实Excel UI显示2.00倍/45.00%/40.00%/11.67% |
| P14 | 模型称R7 Word在Linux渲染为1页；同文件在Windows实际渲染2页 | 两页内容完整，无裁切；字体与Office版本影响分页，不能保证跨平台像素/页数相同。R8独立Windows渲染1页，实际查看标题、指标表、3条观察完整 |
