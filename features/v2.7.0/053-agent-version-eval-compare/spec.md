# Feature: 智能体版本对比评测（同一数据集 × 双版本）

> **本文档定位 — 纯 What（需求口径，不随代码漂移）**
>
> spec 只回答 **做什么 / 验收标准 / 不做什么**。
> **所有 How（决策、数据流、字段、API、Service、前端、文件清单、性能指标）一律不写在这里。**
> How 的唯一真相在 [design.md](./design.md)（接手必读）与 [tasks.md](./tasks.md)（执行流水）。

**关联 PRD**: 用户需求（2026-09-05）：评测功能需要支持对同一个智能体的不同版本进行评测，比较哪个版本准确性更高。
**优先级**: P0
**所属版本**: v2.7.0
**依赖**: 无新增 feature 依赖（复用既有 flow_version 版本列表与评估执行链；评测按版本执行的能力已存在）

> **范围边界**
> - **本次纳入**：
>   - **一键双版本对比评测**：选择智能体 + 两个不同版本 + 一份数据集（新上传或复用历史评测的数据集），系统自动跑两份评测并给出对比结果
>   - **数据集复用**：创建评测时可选复用历史评测的数据集（不重复上传 CSV，保证对比口径一致）
>   - 评测列表的**对比组展示**与对比入口
>   - **对比视图**：两版本总分（F1/召回/精确）并排 + 差值 + 结论；逐题对比表（每题两版本得分、变好/变差/持平标记）
> - **本次明确排除**：
>   - 超过两个版本的对比（本期只支持两版本；N 版本对比另起 feature）
>   - 其他评估指标维度（语义一致性等新指标）——本期只对比既有的 F1/召回/精确
>   - 历史评测回填对比组（上线前已有的评测不自动成组）
>   - 对比结果的导出（CSV/Excel 对比报告）

---

## 1. 用户故事

作为 **应用负责人**，
我希望 **一次性用同一份数据集对智能体的两个版本进行评测**，
以便 **直接看到哪个版本准确性更高，无需手工跑两次再人肉对比**。

作为 **应用负责人**，
我希望 **对比结果展示总分差值与逐题差异（变好/变差）**，
以便 **知道新版本在哪些题目上进步、哪些题目上退化，辅助版本发布决策**。

作为 **应用负责人**，
我希望 **创建评测时可以复用历史评测的数据集**，
以便 **不同版本使用完全相同的题目与答案标准，避免重复上传导致的口径偏差**。

---

## 2. 验收标准

### 2.1 对比评测创建

- **AC-01** — WHEN 用户创建对比评测（指定智能体、两个不同版本、一份数据集）, THE SYSTEM SHALL 创建两条评测记录（携带同一对比组标识、引用同一数据集），并自动开始两份评测任务。
- **AC-02** — IF 两个版本相同, THEN THE SYSTEM SHALL 返回参数错误并终止创建。
- **AC-03** — WHEN 用户创建评测时选择「复用历史评测的数据集」, THE SYSTEM SHALL 使用该历史评测的原始数据集文件，且允许指定与历史评测不同的版本；IF 所选历史评测不属于当前用户, THEN 返回无权限/不存在。
- **AC-04** — WHEN 用户按既有方式创建单版本评测（不指定第二版本）, THE SYSTEM SHALL 行为与现在完全一致（普通评测，不进对比组）。

### 2.2 评测列表与对比入口

- **AC-05** — WHEN 评测列表中存在对比组, THE SYSTEM SHALL 将同组的两条评测相邻分组展示，并提供「对比」入口。
- **AC-06** — IF 对比组中某条评测被删除, THEN 剩余一条按普通评测展示，对比组自动解除。

### 2.3 对比视图

- **AC-07** — WHEN 用户打开对比组, THE SYSTEM SHALL 并排展示两版本的总分（F1、召回、精确）与各项差值，并给出结论：哪个版本准确性更高（比较优先级：F1 → 召回 → 精确）。
- **AC-08** — 对比视图 SHALL 提供逐题对比表：每题两版本的得分（指标可切换：F1/召回/精确），并标注变好/变差/持平；IF 两版本题目集不一致, THEN 按题目文本匹配，无法匹配的题目单独标注。
- **AC-09** — IF 某题在某版本中为「无法判定」（N/A）, THEN 对比表中标注 N/A，且该题不参与差值计算。
- **AC-10** — IF 任一版本评测失败或尚未完成, THEN 对比视图 SHALL 展示该版本的状态（进行中/失败及原因），并仍展示已完成版本的数据。
- **AC-11** — IF 两版本总分均为「无法判定」（N/A）, THEN 结论 SHALL 为「无法比较」。

### 2.4 权限与租户隔离

- **AC-12** — 对比查询接口与评测列表同权限口径（仅登录用户可访问自己的评测与对比）。
- **AC-13** — WHERE 多租户开启, THE SYSTEM SHALL 仅返回当前租户的评测与对比数据。

---

## 3. 边界情况

- 对比组最多两条评测（本期只支持两版本对比）。
- 同一数据集的两份评测逐题匹配：优先按题目顺序对齐（数据集相同 → 顺序一致）；顺序不一致时按题目文本匹配。
- 数据集复用所引用的历史评测被删除：复用关系在创建时已复制引用（文件在对象存储中独立存在），新评测不受影响。
- 版本在评测期间被修改/删除：评测按创建时的版本快照执行（既有行为），对比视图仍按评测结果展示。
- 对比组中两条评测的智能体不同（异常数据）：对比接口拒绝并提示。
