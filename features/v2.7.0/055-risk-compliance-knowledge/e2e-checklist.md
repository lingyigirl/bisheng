## Platform 前端

### AC-01: 预设分类标签
- [ ] 步骤 1: 以 admin 登录 Platform，导航到 知识库 → 新建知识库（选择嵌入模型）
- [ ] 步骤 2: 创建完成后进入知识库详情 → 标签中心（或文档打标弹窗）
- [ ] 预期: 可直接选用「行内制度 / 监管法规 / 行业分析 / 历史案例」四个预设标签，无需手工创建

### AC-02: 打标弹窗新建标签即时生效
- [ ] 步骤 1: 知识库详情 → 选中文档 → 打标弹窗 → 输入新标签名 → 保存
- [ ] 步骤 2: 不刷新页面，回到文档列表查看该文档的标签列
- [ ] 预期: 新标签立即出现在文档行与标签筛选器中（回归 2026-09-06 的「新建标签后保存不生效」bug）

### AC-04: 标签中心建/改/删
- [ ] 步骤 1: 知识库详情 → 工具栏「标签中心」→ 新建/重命名一个标签
- [ ] 步骤 2: 删除一个已打在某文档上的标签（弹二次确认）
- [ ] 预期: 文档列表中该文档不再显示此标签；检索过滤口径同步更新；文档展示无残留

### AC-07: 失效/未生效标识
- [ ] 步骤 1: 给某文档设昨天为失效日（或明天为生效日）并保存
- [ ] 步骤 2: 回到文件列表查看该行
- [ ] 预期: 行内出现「已失效」（红）/「未生效」（蓝）badge，文档仍可查看与维护（不参与检索，API e2e 已验证）

### AC-14: 命中测试弹窗
- [ ] 步骤 1: 知识库详情 → 工具栏「命中测试」→ 输入与该库内容相关/无关的问句 → 测试
- [ ] 步骤 2: 观察结果区
- [ ] 预期: 展示命中文档名、片段、相关度分数（4 位小数）；底部统计条显示「N 篇失效 / N 篇未生效被排除」；无关问句显示空命中提示；Enter 可快捷触发

### AC-17: 权限门
- [ ] 步骤 1: 用无该库权限的普通账号登录（如 test）
- [ ] 步骤 2: 访问该知识库详情页
- [ ] 预期: 无「编辑」入口（Header 编辑按钮隐藏）、无「标签中心」入口；「命中测试」可点但后端按读权限拒绝（业务码 403）；普通账号创建/编辑标签被拒

## 工作流检索节点（AC-03/09/10/12/13）

### AC-03: 标签过滤
- [ ] 步骤 1: 创建/打开一个 rag（知识检索）工作流，检索节点选择含多标签文档的知识库，配置 tags（点选分类标签 chips）
- [ ] 步骤 2: 运行对话，提问命中两类文档的混合问题
- [ ] 预期: 只召回带所选标签的文档片段；未选标签的库不受影响（逐库解析口径）

### AC-09/AC-10: 多库权重与优先级
- [ ] 步骤 1: 知识库编辑弹窗给 A 库设 weight=2、B 库设 weight=1（或 A 优先、B 普通）
- [ ] 步骤 2: rag 节点同时选择 A、B 两库（都不配 top_k 上限更明显），提问两库都命中的问题
- [ ] 预期: 高权重库结果排前；优先级场景——优先组先召回 top_k，不足再补普通组；weight=0 的库完全不参与召回

### AC-12/AC-13: top_k 与相似度阈值
- [ ] 步骤 1: 节点配置 top_k=3 与 score_threshold=0.3，运行对话
- [ ] 预期: 召回片段数 ≤3，低分片段被过滤
- [ ] 步骤 2: 清空两个参数（空 = null）再运行
- [ ] 预期: 与未配置前行为一致（top_k=100 默认、无阈值），回归既有工作流不受影响

## 外部数据分流（AC-15/AC-16）

### AC-15: 实时数据不进知识库
- [ ] 检查: 工作流中企查查/天眼查/征信类实时查询全部经 MCP 工具节点调用
- [ ] 预期: 知识库列表中不存在这些实时数据的上传文档；检索结果不含实时查询数据

### AC-16: 静态资料入库同口径
- [ ] 步骤: 上传一份外部评级报告/行业分析 PDF 到知识库，打标 + 设生效日期
- [ ] 预期: 与行内文档同样受分类/时效/权重约束（API e2e 已用 txt 验证同管线，此处验证 PDF 解析）
