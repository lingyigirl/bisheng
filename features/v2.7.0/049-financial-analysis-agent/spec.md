# Feature: 财务分析智能体（F049）

> 小功能 track：配置级新增工作流智能体实例（与 F048 征信分析智能体同模式）。无跨 Feature 契约变更、无新增领域对象。

**关联 PRD**: 会话需求（2026-09-01）：新增财务分析智能体——上传公司财务报表，输出公司基本信息、财务指标概览（自动计算）、财务状况分析、现金流量分析、风险提示与综合评价（含授信建议）。
**优先级**: P0
**所属版本**: v2.7.0
**依赖**: 无（复用工作流引擎；文本提取/OCR 回退代码与 F048 共用同一实现）

> **范围边界**
> - **本次纳入**：
>   - 新建工作流应用「财务分析智能体」并上线
>   - 表单上传财务报表 PDF（可多文件；资产负债表/利润表/现金流量表，单文件含多表或分文件均可）
>   - 文本 PDF 直读 + 扫描件 MinerU OCR 回退
>   - 两段式：LLM 提取三表科目数据 JSON → **code 节点自动计算**财务指标（资产负债率、收益率、流动比率、速动比率、收入/利润现金保障倍数等）与趋势 → LLM 生成五段式报告
>   - 五段式输出：公司基本信息 / 财务指标概览 / 财务状况分析 / 现金流量分析 / 风险提示与综合评价（含授信建议）
> - **本次明确排除**：
>   - 报表数据入库 / 知识库留存
>   - 多期（>3 期）长序列趋势建模（本期支持报告内已有期数，通常 2-3 期）
>   - 审计级勾稽关系校验（资产负债表平衡校验等，仅作风险提示维度）
>   - 评级/授信建议的监管口径（输出注明内部参考，同 F048）

## 1. 用户故事

作为 **银行信贷人员**，
我希望 **上传企业财务报表后自动完成指标计算与财务分析**，
以便 **快速判断企业财务状况与授信风险，无需手工测算**。

## 2. 验收标准

| ID | 操作 | 预期结果 |
|----|------|---------|
| AC-01 | 上传含资产负债表/利润表/现金流量表的财务报表 PDF（文本版） | 生成五段式报告（公司基本信息 / 财务指标概览 / 财务状况分析 / 现金流量分析 / 风险提示与综合评价） |
| AC-02 | 上传扫描版报表 PDF | 自动走 MinerU OCR 回退并同样生成五段式报告 |
| AC-03 | 财务指标概览章节 | 指标由 code 节点计算而非 LLM 心算；包含资产负债率、净利率/毛利率（按报表可得）、流动比率、速动比率、收入现金保障倍数、利润现金保障倍数，并按报告期数给出变化趋势；**计算口径与数值可核对** |
| AC-04 | 指标计算所需科目缺失（如无现金流量表） | 相关指标标注「报表未提供」而非编造 |
| AC-05 | 风险提示章节 | 覆盖应收账款激增、库存积压、财报异常（造假/粉饰信号：如利润与现金流背离、应收与收入增速背离）等风险点，并给出风控措施与授信建议（内部参考提示同 F048） |
| AC-06 | 不传文件直接提交 | 返回明确提示而非报错崩溃 |
| AC-07 | 超长报告 | 截断至上限并注明，不静默丢尾 |
| AC-08 | OCR 不可用且 PDF 无文本层 | 返回明确解析失败提示，不编造内容 |

## 3. 边界情况

- 单文件含三张表 vs 三个文件分表上传：均支持，LLM 提取阶段自动归集科目
- 报表期数不一（如资产负债表 2 期、利润表 1 期）：趋势按可得期数计算
- LLM 提取 JSON 不合法：code 容错解析（截取首尾大括号），仍失败则报告注明「数据提取失败，无法计算指标」，不静默
- 手工报表（Excel 导图）字段名不标准：LLM 提取阶段做科目名归一

## 4. 设计与实现（指针）

- 工作流结构：start → input(表单：财务报表文件) → code「报表文本提取」→ llm「财务数据提取」(output_user=false, 严格 JSON) → code「指标计算」→ llm「财务分析报告生成」(output_user=true) → end
- 模型：deepseek-v4-flash-无思考（id=17）
- 创建方式：F048 同款模板改造 + API 创建上线
- e2e：合成财务报表 PDF（reportlab）验证指标计算数值与五段式输出
