# Feature: 智能体运行状态监控（监控看板 + 调用日志）

> **本文档定位 — 纯 What（需求口径，不随代码漂移）**
> spec 只回答 **做什么 / 验收标准 / 不做什么**。How 的唯一真相在 [design.md](./design.md) 与 [tasks.md](./tasks.md)。

**关联 PRD**: 会话需求（2026-09-01）：支持智能体运行状态监控，统计调用总量、成功率、最大/平均响应时间并以图表展示；可查看每个智能体的使用情况与运行状态；平台提供监控看板与调用日志统计，覆盖对话、工作流、模型调用等运行记录；并在首页展示。
**优先级**: P0
**所属版本**: v2.7.0
**依赖**: 无（复用遥测事件体系与既有看板引擎）

> **范围边界**
> - **本次纳入**：
>   - 智能体运行监控指标：调用总量、调用成功率、最大响应时间、平均响应时间，指标卡 + 图表展示
>   - 每个智能体的使用情况与运行状态（按智能体维度的调用量/成功率/响应时间排名与明细）
>   - 智能体调用日志：覆盖对话（工作流/助手/灵思应用）与模型调用的运行记录，支持分页与筛选
>   - 首页（平台统计看板）集成展示上述监控能力
>   - 5 分钟准实时的监控数据同步
> - **本次明确排除**：
>   - 阈值告警 / 通知推送（另起 feature）
>   - 监控数据导出（CSV/Excel）
>   - 知识库、数据集等其他资源的运行监控（本期「智能体」口径 = 工作流 / 助手 / 灵思 三类应用）
>   - 自定义监控看板编辑器能力（复用既有看板引擎渲染，本期仅扩展预置看板组件，不新增编辑器交互）
>   - 跨租户汇总视图（每个租户只看自己的数据，与既有统计看板口径一致）

---

## 1. 用户故事

作为 **平台管理员**，
我希望 **在首页看到智能体调用总量、成功率、响应时间的准实时指标**，
以便 **快速掌握平台智能体的整体健康度，无需进入逐个应用页面**。

作为 **平台管理员**，
我希望 **看到每个智能体的调用量、成功率与运行状态的排名与明细**，
以便 **快速定位异常或高负载的智能体**。

作为 **平台管理员 / 应用负责人**，
我希望 **查询智能体与模型的调用日志（状态、耗时、时间、用户）**，
以便 **排查失败调用与性能问题**。

---

## 2. 验收标准

### 2.1 数据采集与指标口径

- **AC-01** — WHEN 工作流 / 助手 / 灵思应用的一次运行结束, THE SYSTEM SHALL 在遥测事件中记录该次运行的 `status`（success / failed）与耗时（含失败路径）。
- **AC-02** — WHERE 平台运行, THE SYSTEM SHALL 每 5 分钟将智能体运行事件与模型调用事件纳入监控数据统计；IF 同步中断后恢复, THEN THE SYSTEM SHALL 补全缺失数据且不产生重复统计。
- **AC-03** — THE SYSTEM SHALL 对每个智能体提供以下监控指标：调用总量、调用成功数、调用成功率（= 成功数 / 总量）、平均响应时间、最大响应时间、最后活跃时间。
- **AC-04** — WHEN 一次智能体运行包含多次模型调用, THE SYSTEM SHALL 按「智能体运行」粒度统计调用量与成功率（一次智能体运行记 1 次调用，不按内部模型调用次数重复计数）；每次模型调用单独记录为一条模型调用记录（含状态、耗时、token），供调用日志查询与明细展示。

### 2.2 首页监控看板（扩展现有统计看板）

- **AC-05** — WHEN 管理员打开首页统计看板, THE SYSTEM SHALL 展示监控指标卡：今日智能体调用总量、今日调用成功率、今日平均响应时间、今日最大响应时间。
- **AC-06** — WHEN 管理员打开首页统计看板, THE SYSTEM SHALL 以图表展示：近 N 天智能体调用趋势（按天，N 可由时间筛选联动）、各智能体调用量分布（Top N，含成功/失败构成）。
- **AC-07** — WHEN 管理员修改看板时间筛选, THE SYSTEM SHALL 联动刷新全部监控指标卡与图表。
- **AC-08** — WHEN 管理员查看单个智能体的使用情况, THE SYSTEM SHALL 展示该智能体的调用总量、成功率、平均/最大响应时间与最近活跃时间。

### 2.3 调用日志

- **AC-09** — WHEN 管理员打开调用日志, THE SYSTEM SHALL 展示最近的运行记录（智能体运行记录：智能体名称、应用类型、调用用户、状态、响应耗时、发生时间；模型调用记录：模型名、状态、耗时、token 消耗、发生时间），按时间倒序分页（默认近 7 天）。
- **AC-10** — WHEN 管理员按智能体 / 模型 / 记录类型 / 状态（成功 / 失败）/ 时间范围筛选, THE SYSTEM SHALL 返回符合条件的调用记录。
- **AC-11** — WHEN 管理员查看一条调用记录, THE SYSTEM SHALL 展示该次运行内的模型调用明细（模型名、状态、耗时、token 消耗，如事件中存在）。
- **AC-12** — IF 智能体已被删除, THEN THE SYSTEM SHALL 仍可查询其历史调用记录（显示记录时的名称快照）。

### 2.4 权限与租户隔离

- **AC-13** — WHERE 多租户开启, THE SYSTEM SHALL 仅返回当前租户的监控数据与调用日志。
- **AC-14** — IF 用户无看板权限（board）, THEN THE SYSTEM SHALL 按既有看板权限规则不展示监控看板与调用日志。

---

## 3. 边界情况

- 当今日尚无任何调用时，指标卡显示 0，图表显示空态（不报错）。
- 当智能体运行事件缺少 `status`（历史数据，未回填前），该次运行按「失败/未知」统计还是剔除？——**口径：历史无 status 事件不纳入成功率统计（仅计入调用总量）**，新数据自 AC-01 生效后全部带 status。
- 当一次运行耗时异常大（> 阈值），最大响应时间指标如实展示，不截断。
- 调用日志时间范围上限 90 天；超过返回参数错误。
- 中间表同步与看板查询跨天时，按既有看板时间桶口径（DB 时钟）对齐。
- 权限与租户口径与既有统计看板完全一致，不新增独立权限体系。
